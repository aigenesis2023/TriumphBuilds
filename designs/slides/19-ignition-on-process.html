Example — keyless system
ignition-on process.

Yellow —What customer perceives as being the state of bike
Blue —Actual state of bike
Step-by-step ignition-on flow with perceived vs actual state mapping
Perceived state
Bike is "Off"
01User presses either "power" or "start" button
02Keyless control unit (KCU) wakes up
03KCU checks for recognised key being available and for matching ESL identification.
04If the KCU finds a recognised key and confirms the ESL identification, it will apply power to the "12v ignition" input to all other components
Perceived state
Bike is "On"
05All other components wake up simultaneously, except ECU which will only wake up if the kill switch is in the "run" position
06When ECU wakes, it queries key authentication state from KCU (KCU responds key is authenticated)
07ECU and KCU then exchange security keys as final step of immobiliser functionality
Perceived state
Bike can start
08If ECU-KCU exchange is OK, engine can be started.

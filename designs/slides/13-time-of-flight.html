RF = Radio Frequency
How the keyless system defeats relay attacks
01

The latest Keyless chipset includes a timing check to safeguard against relay attacks — RF repeaters used by thieves to clone the signal and steal the motorcycle.

02

The system checks the time taken to return the handshake message. Unless the fob is directly talking to the security module, it takes too long and fails — so the bike would not unlock.

03

If a repeater were used by a potential thief, the lag would not be able to imitate the speed of the handshake from the original fob.

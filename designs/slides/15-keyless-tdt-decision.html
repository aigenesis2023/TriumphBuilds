Pairing Keys
With the TDT

Adding a new key vs Re-registering all keys · Keyless Systems

Add
New Key

Pairs one key at a time to the immobiliser system, provided the maximum number of paired keys has not been reached. An attack delay of 5 minutes must pass for each key pairing.

Re-Register
All Keys

Erases all keys from immobiliser memory except the key used to turn ignition ON at the start. Allows multiple keys to be paired up to the maximum. 5-minute attack delay per pairing.

! Important
Make sure keys are separated before starting key pairing. Only the key being paired should be in close proximity to the LF antenna — placing two keys close to it can cause the pairing process to fail.
